HƯỚNG DẪN CÀI MOD VIỆT HÓA (Atmosphere LayeredFS)
==================================================

Cách cài
--------
1. Chép nguyên thư mục `atmosphere` (trong output\) vào THƯ MỤC GỐC của thẻ nhớ Switch
   (thẻ nhớ đã có sẵn thư mục "atmosphere" do Atmosphere tạo — gộp vào, giữ nguyên phần cũ).
2. Kết quả đúng:  <thẻ nhớ>\atmosphere\contents\<TitleID>\romfs\...
3. Khởi động lại máy rồi vào game — mod được nạp tự động.
4. Gỡ mod: xoá thư mục <TitleID> tương ứng trong atmosphere\contents\.

  (đã dịch 26.844 TextId + vá 14 font tiếng Việt). Không cần chọn ngôn ngữ đặc biệt —
  mọi khe ngôn ngữ đều đã được ghi tiếng Việt.

Game CÓ BẢN UPDATE — cài trên SWITCH: ID base + bundle đúng phiên bản (QUAN TRỌNG)
----------------------------------------------------------------------------------
Atmosphere key LayeredFS theo ID *base* và đè lên romfs đã GỘP (base + update), nên:
  - Đặt mod ở ID base (base ...000), NHƯNG nội dung phải là bundle ĐÚNG phiên bản máy đang chạy.
  - CHỈ đặt 1 folder. Đặt cả base + update -> TREO MÀN HÌNH CHỜ.
Ví dụ MONOPOLY (máy chạy update v1.6):
  atmosphere/contents/01002C201BC40000/romfs/Data/data.unity3d   (bundle v1.6)
  -> KHÔNG đặt thêm folder 01002C201BC40800.
Eden/yuzu thì nạp mod theo ID *update* nên dùng folder ...800 (trong %APPDATA%/eden/load/).

The Legend of Zelda: Tears of the Kingdom — LƯU Ý QUAN TRỌNG
----------------------------------------------------------
Mod gồm 3 thư mục (file rời trong RomFS -> LayeredFS thay trực tiếp, KHÔNG cần patch pak):
  romfs\Mals\USen.Product.142.sarc.zs        -> toàn bộ text (47.800 chuỗi, 1.511 file MSBT)
  romfs\Font\Font.Nin_NX_NVN.bfarc.zs        -> font đã vá tiếng Việt
  romfs\System\Resource\ResourceSizeTable... -> BẢNG KÍCH THƯỚC RESOURCE (BẮT BUỘC, xem mục 3)

1) NGÔN NGỮ TRONG GAME = **English** (mod ghi đè khe USen; chọn ngôn ngữ khác sẽ ra ngôn ngữ đó).
2) HAI GÓI ĐANG CÓ (dùng cái khớp ý bạn):
   - `output/atmosphere/contents/0100F2C0115B6000/`  -> bản dịch CỦA MÌNH (100%).
   - `output/TRT143/.../0100F2C0115B6000/`           -> PORT bản Việt hoá của team "The Red Team" sang 1.4.3
       (47.336 nhãn giọng TRT + 143 nhãn mới của 1.4.3 lấy từ bản của mình). Đây là gói đã chạy tốt trên 1.4.3.
   Cách cài: xoá sạch `...\eden\load\0100F2C0115B6000\romfs\` (hoặc folder trên thẻ) rồi chép **cả 3 thư mục**
   `Mals` + `Font` + `System` của gói muốn dùng. Chép thiếu `System/` -> TREO ở màn hình "Launching...".
3) 🚨 BẢNG KÍCH THƯỚC RESOURCE (ResourceSizeTable) — LÝ DO TREO GAME PHỔ BIẾN NHẤT:
   TotK dùng `System/Resource/ResourceSizeTable.Product.<ver>[.Nin_NX_NVN].rsizetable.zs` để biết kích thước
   GIẢI NÉN của từng resource. Thay Mals/Font mà không vá bảng -> engine cấp phát thiếu -> treo/fatal.
   - Máy chạy **1.4.3** -> game đọc `ResourceSizeTable.Product.143.Nin_NX_NVN.rsizetable.zs` (bản 1.4.3 vẫn đọc
     `Mals/USen.Product.142.sarc.zs`; số `Product.*` là phiên bản DỮ LIỆU, không phải phiên bản game).
   - Vá lại sau mỗi lần build: `python tools/patch_totk_rstb.py` (tự kiểm roundtrip; nén KHÔNG từ điển cho khớp gốc).
4) KHÁC PHIÊN BẢN: nếu máy chạy phiên bản update khác -> Dump RomFS đúng phiên bản rồi build lại
   (`python tools/build_totk_mod.py` hoặc `python tools/build_totk_trt_mod.py --trt <patch cũ>`), rồi vá RSTB.
   Nguồn dữ liệu (ngoài OneDrive): `E:\RomFS_Dump\0100F2C0115B6000\romfs\` (cần `Pack\ZsDic.pack.zs` = từ điển zstd).
5) Đặt ở **ID base** `atmosphere/contents/0100F2C0115B6000/romfs/...` và CHỈ 1 folder.
   Eden/yuzu: dùng `%APPDATA%\eden\load\0100F2C0115B6000\romfs\...`
6) QA: `python tools/qa_text.py --game totk` (đã PASS; 0 lỗi).

Nintendo Switch Sports — LƯU Ý QUAN TRỌNG
-----------------------------------------
Mod gồm 3 thư mục (LayeredFS thay trực tiếp, KHÔNG cần patch pak):
  romfs\Mals\USen.Product.150.sarc.zs                              -> toàn bộ text (250 file MSBT, 24.597 chuỗi)
  romfs\Font\Font.Nin_NX_NVN.bfarc.zs                              -> font GỐC + tiêm glyph tiếng Việt
  romfs\System\Resource\ResourceSizeTable.Product.150.rsizetable.zs -> BẢNG KÍCH THƯỚC RESOURCE (BẮT BUỘC)

1) NGÔN NGỮ TRONG GAME = **English**.
2) 🚨 Chép THIẾU thư mục `System\Resource\` -> engine không biết kích thước resource -> TREO/crash khi vào game.
   (Bảng gốc ghi font 13.901.528 byte, còn font mod 13.921.644 byte -> vượt hạn mức.)
3) Sau mỗi lần build lại text/font phải chạy: `python tools/patch_sws_rstb.py`
4) QA: `python tools/qa_text.py --game switchsports` (PASS).

Ori and the Blind Forest (DE) — LƯU Ý QUAN TRỌNG
------------------------------------------------
Sau khi chép mod, PHẢI đặt NGÔN NGỮ TRONG GAME = **English**.
Lý do: game không có slot tiếng Việt; bản dịch ghi ĐÈ LÊN KHE TIẾNG ANH (cùng cách với Will of the Wisps).
Mod gồm: romfs\Data\data.unity3d (đã vá 679 mục text + 78 glyph tiếng Việt vào atlas font).

Ori and the Will of the Wisps — LƯU Ý QUAN TRỌNG
------------------------------------------------
Sau khi chép mod, PHẢI đặt NGÔN NGỮ TRONG GAME = **English**.

Hogwarts Legacy — mod gồm 2 phần
--------------------------------
A. Hội thoại + giao diện  (BẮT BUỘC — đây là phần chính):
     romfs\Phoenix\Content\Paks\pakchunk0-Switch_p.pak
       -> patch pak (UE4) chứa bản dịch cho CẢ 14 ngôn ngữ của game
          (arAE deDE enUS esES esMX frFR itIT jaJP koKR plPL ptBR ruRU zhCN zhTW),
          nên đặt console ở ngôn ngữ nào cũng hiện tiếng Việt.
       -> Lý do phải dùng pak: file Localization/SWITCH/*.bin của game nằm BÊN TRONG
          pakchunk0-Switch.pak, engine mount pak TRƯỚC RomFS nên file .bin rời bị bỏ qua.

B. Font tiếng Việt:
     romfs\Engine\Content\SlateDebug\Fonts\LastResort.ttf
       -> thay font dự phòng của UE (Lato), phủ 100% ký tự tiếng Việt dùng trong mod.
       -> File này là file RỜI (có trong Manifest_NonUFSFiles) nên LayeredFS thay được.

Ghi chú
-------
- Thư mục romfs\Phoenix\Content\Localization\SWITCH\*.bin (bản rời) vẫn được giữ cho
  đầy đủ, nhưng phần chính là patch pak ở mục A.
- Định dạng text: AVAFDICT 2.0 (Unreal Engine 4.27).
- Không ghi đè/xoá file nào của game; toàn bộ là lớp phủ (overlay) — gỡ thư mục mod là về nguyên trạng.
