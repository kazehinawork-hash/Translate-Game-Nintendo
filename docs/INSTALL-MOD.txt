HƯỚNG DẪN CÀI MOD VIỆT HÓA (Atmosphere LayeredFS)
==================================================

Cách cài
--------
1. Chép nguyên thư mục `atmosphere` (trong output\) vào THƯ MỤC GỐC của thẻ nhớ Switch
   (thẻ nhớ đã có sẵn thư mục "atmosphere" do Atmosphere tạo — gộp vào, giữ nguyên phần cũ).
2. Kết quả đúng:  <thẻ nhớ>\atmosphere\contents\<TitleID>\romfs\...
3. Khởi động lại máy rồi vào game — mod được nạp tự động.
4. Gỡ mod: xoá thư mục <TitleID> tương ứng trong atmosphere\contents\.

Các game có trong gói
---------------------
- Hogwarts Legacy          TitleID 0100F7E00C70E000
- Hades II                 TitleID 0100A00019DE0000
- Nintendo Switch Sports   TitleID 0100D2F00D5C0000
- Ori and the Will of the Wisps   TitleID 01008DD013200000
- Ori and the Blind Forest (DE)   TitleID 010061D00DB74000
- Kirby and the Forgotten Land    TitleID 01004D300C5AE000
- It Takes Two                    TitleID 010092A0172E4000
- MONOPOLY (2024)                 TitleID 01002C201BC40000   (xem mục "có bản UPDATE" bên dưới)

Game CÓ BẢN UPDATE — chỉ đặt ĐÚNG 1 TitleID (QUAN TRỌNG)
--------------------------------------------------------
Mod phải nằm ở ID khớp PHIÊN BẢN MÁY ĐANG CHẠY, và CHỈ đặt 1 ID:
  - máy ĐÃ CÀI update  -> dùng ID của bản update (base ...000 -> update ...800)
  - máy CHỈ có base     -> dùng ID base
Đặt CẢ HAI (base + update) cùng lúc -> TREO MÀN HÌNH CHỜ (hai phiên bản bundle bị nạp lẫn).
Ví dụ MONOPOLY: máy đang chạy update v1.6 -> CHỈ dùng TitleID 01002C201BC40800.
(Bản mod build từ base v1.0 là cho máy KHÔNG cài update — đặt chung với bản update là hỏng.)

Ori and the Blind Forest (DE) — LƯU Ý QUAN TRỌNG
------------------------------------------------
Sau khi chép mod, PHẢI đặt NGÔN NGỮ TRONG GAME = **English**.
Lý do: game không có slot tiếng Việt; bản dịch ghi ĐÈ LÊN KHE TIẾNG ANH (cùng cách với Will of the Wisps).
Mod gồm: romfs\Data\data.unity3d (đã vá 679 mục text + 78 glyph tiếng Việt vào atlas font).

Ori and the Will of the Wisps — LƯU Ý QUAN TRỌNG
------------------------------------------------
Sau khi chép mod, PHẢI đặt NGÔN NGỮ TRONG GAME = **English**.
Lý do: game không có slot tiếng Việt; bản dịch được ghi ĐÈ LÊN KHE TIẾNG ANH.
Nếu đặt ngôn ngữ khác (Pháp/Đức/Nhật…) game vẫn hiện ngôn ngữ đó như bình thường.
Mod gồm: romfs\Data\data_*.unity3d (102 bundle text + 1 bundle font).

Hogwarts Legacy — mod gồm 2 phần
--------------------------------
A. Hội thoại + giao diện  (BẮT BUỘC — đây là phần chính):
     romfs\Phoenix\Content\Paks\pakchunk0-Switch_p.pak
       -> patch pak (UE4) chứa bản dịch cho CẢ 14 ngôn ngữ của game
          (arAE deDE enUS esES esMX frFR itIT jaJP koKR plPL ptBR ruRU zhCN zhTW),
          nên đặt console ở ngôn ngữ nào cũng hiện tiếng Việt.
       -> Lý do phải dùng pak: file Localization/SWITCH/*.bin của game nằm BÊN TRONG
          pakchunk0-Switch.pak, engine mount pak TRƯỚC RomFS nên file .bin rời bị bỏ qua.

B. Font tiếng Việt:
     romfs\Engine\Content\SlateDebug\Fonts\LastResort.ttf
       -> thay font dự phòng của UE (Lato), phủ 100% ký tự tiếng Việt dùng trong mod.
       -> File này là file RỜI (có trong Manifest_NonUFSFiles) nên LayeredFS thay được.

Ghi chú
-------
- Thư mục romfs\Phoenix\Content\Localization\SWITCH\*.bin (bản rời) vẫn được giữ cho
  đầy đủ, nhưng phần chính là patch pak ở mục A.
- Định dạng text: AVAFDICT 2.0 (Unreal Engine 4.27).
- Không ghi đè/xoá file nào của game; toàn bộ là lớp phủ (overlay) — gỡ thư mục mod là về nguyên trạng.
